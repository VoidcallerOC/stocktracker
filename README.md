# CT TCG Restock Tracker

A planned tracker for retail restocks of sealed **Pokémon TCG** and **One Piece Card Game** products at major retailers in **Connecticut**. Every inventory observation will show its source and how fresh it is.

## Current status

**Pre-MVP. Nothing is deployed. There are no live retailer integrations and no UI.**

- No retailer inventory source is authorized yet:
  - Best Buy: PARTIAL
  - Walmart: BLOCKED
  - Target: BLOCKED
  - GameStop: UNVERIFIED
- Until a source is authorized, retailer coverage will rely on community reports.
- The first implementation (source-access audit, inventory core logic, draft database schema, tests) is under review in a draft pull request and has **not** been merged here.

`main` contains only reviewed work.
